# VSP AI/ML Training — default dependencies
#
#   .venv/bin/python -m pip install -r requirements.txt
#
# ...or, from inside a Jupyter notebook cell, installing into the running kernel:
#
#   %pip install -r requirements.txt
#
# This file is the SAFE default: it installs exactly what the module currently in
# session needs, and nothing else. Running it cannot leave you worse off, and it is
# what the LSN-0.1 notebook tells you to run when an import fails.
#
# ------------------------------------------------------------------------------
# Dependencies are staged by module, because installing everything up front is the
# most common way to arrive at a session blocked:
#
#   requirements.txt        -> MOD-0   before 1 Sep      ~350 MB   (this file)
#   requirements-mod1.txt   -> MOD-1   before 28 Sep     +~650 MB  (adds PyTorch)
#   requirements-full.txt   -> legacy full-program list; DO NOT install to get
#                              started — it pulls CUDA-only packages that fail
#                              on macOS. Kept for reference only.
