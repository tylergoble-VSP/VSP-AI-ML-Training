# Educational Context:
# requirements.txt is a standard way to specify project dependencies.
# 
# Key Concepts:
# 1. Package name: Name of the Python package (e.g., "numpy")
# 2. Version constraint: Minimum version required (e.g., ">=1.21.0")
#    - >= means "at least this version"
#    - == means "exactly this version"
#    - ~= means "compatible version"
# 3. Installation: pip install -r requirements.txt
#
# Why use requirements.txt?
# - Reproducible environments (same packages, same versions)
# - Easy setup (one command installs everything)
# - Version control (track what versions work)
# - Share with others (they get exact same environment)
